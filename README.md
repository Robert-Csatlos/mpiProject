# mpiProject
The files used for the MPI Project SAT algorithms analysis.

---PEREQUISITES---

To run these programs you first need these PYTHON plugins:
-dd
-psutil


How to install?

Write these two commands in your terminal, if you have "pip" istalled, if not, you can install it following the instructions listed here: https://packaging.python.org/en/latest/tutorials/installing-packages/

After installing pip, you will have to install "dd" and "psutil" with the following commands listed below:

pip install dd

pip install psutil

---HOW TO USE---

There are 4 folders, each with the corresponding algorithm.

To test the algorithm specified in the folder, make sure to open the folder of the algorithm you want to try running.

Run the .py file. You can run the .py file if you have python installed, then right click in the folder, select "open in terminal" then write the name of the file you want to run like this: 

.\name.py

replacing the "name" with the name of the algorithm in the folder.

Write (numbers only) how many times you want to repeat the algorithm in the session as "instances", an instance being one line of data fed to the algorithm. One instance means one line of data, ten instances means ten lines of data, each line being a problem, generated on the spot that requires that algorithm to be solved.

Check the output.txt file for the output and the stats.txt file for the run-time and ram. They are automatically created when running the program.


---DISCLAIMER---

The test values made on other devices might be different from the values that I got in the paper, since the PC's might have other peripherics and benchmarks.

the input output and stats text files don't need to be created, they are automatically created by the program if they don't exist already.
